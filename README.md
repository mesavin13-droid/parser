# Tech Deal Hunter

Персональный помощник для поиска потенциально выгодных товаров с уведомлениями Telegram. Стартовая конфигурация: Новосибирск, техника и инструменты, скидка от 25%, ожидаемая прибыль от 1 500 ₽.

## Что делает

- читает явно настроенные RSS/Atom-ленты и публичные HTML-страницы поиска Avito;
- поддерживает импорт объявлений и рыночных аналогов в CSV/JSON;
- считает медианную рыночную цену только при наличии минимум трёх аналогов для одной модели;
- исключает старые объявления и устаревшие снимки рыночных цен из расчёта;
- отслеживает последнее появление объявления в источнике и показывает число устаревших записей;
- отправляет очередь всех новых выгодных находок после обработки пакета, в том числе если выгодность подтвердилась благодаря новым аналогам;
- оценивает скидку и предполагаемую прибыль после указанных затрат;
- помечает объявления с признаками неисправности и подозрительных требований оплаты;
- хранит объявления и историю цен в SQLite, не присылает дубликаты повторно;
- отправляет находки в Telegram и поддерживает команды `/deals`, `/stats`, `/scan`, `/id`.

**Важно:** бот не может гарантировать, что товар ещё доступен, исправен или принадлежит автору объявления. Это предварительная оценка; наличие, состояние, комплектность и право собственности нужно проверить лично. Данные из примеров не выдаются за реальные находки.

## Запуск локально

Нужен Python 3.11+; сторонние Python-пакеты не нужны.

```bash
git clone https://github.com/mesavin13-droid/parser.git
cd parser
cp .env.example .env
```

Откройте `.env` и внесите токен бота, полученный у [@BotFather](https://t.me/BotFather). Затем запустите:

```bash
python main.py telegram
```

Напишите боту `/id`, скопируйте ID чата в `TELEGRAM_CHAT_ID` файла `.env` и перезапустите процесс. После этого уведомления будут отправляться в указанный чат.

## Подключение источников

В `.env` есть два списка. Указывайте только источники, к которым у вас есть разрешённый доступ:

- `RSS_FEEDS` — URL RSS/Atom-лент, разделённые точкой с запятой;
- `AVITO_SEARCH_URLS` — URL публичных страниц поиска Avito, также разделённые точкой с запятой. Если у конкретного поиска доступна RSS-выдача, можно указать URL с параметром `format=rss`; бот выберет RSS-парсер.

Пример формата (замените URL своими адресами):

```dotenv
RSS_FEEDS=https://example.org/feed.xml
AVITO_SEARCH_URLS=https://www.avito.ru/novosibirsk/telefony
```

Публичная HTML-структура площадки может меняться. Если карточки не удаётся прочитать, сервер возвращает ошибку или показывает CAPTCHA/ограничение, сбор остановится и покажет причину. **Обход CAPTCHA, антибот-защиты, авторизации и ограничений не выполняется.** В этом случае используйте официальный/разрешённый экспорт, RSS или импорт CSV/JSON.

Проверьте источники одним проходом:

```bash
python main.py scan
```

Периодический опрос (интервал не меньше 60 секунд):

```bash
python main.py watch --interval 300
```

## Автоматическое определение средней рыночной цены

**Вручную загружать средние цены больше не обязательно.** Бот сам использует другие объявления, которые собрал из подключённых источников: сопоставляет их по нормализованному названию модели и считает медианную цену. Текущая проверяемая карточка исключается из собственного сравнения, а прежние объявления этой модели пересчитываются при поступлении новых данных.

Для оценки нужно минимум 3 других сопоставимых предложения. Рыночные цены старше 30 дней по умолчанию не учитываются. Объявление старше 72 часов по дате публикации (либо по последнему появлению в источнике, если дата публикации неизвестна) помечается как устаревшее и не попадёт в /deals или уведомления. Эти пороги можно изменить через `MAX_LISTING_AGE_HOURS` и `MAX_MARKET_DATA_AGE_DAYS`. Если аналогов пока нет, бот помечает карточку «недостаточно рыночных данных» и не отправляет её как подтверждённую выгодную находку. Разные модели, объём памяти, комплектация и состояние могут требовать раздельных поисковых запросов; совпадение названия — это предварительное сопоставление, а не гарантия идентичности товара.

Импорт цен остаётся дополнительным способом повысить качество сравнения. Если предложения уже есть в базе, добавление новых рыночных цен автоматически пересчитывает их оценку. Используйте реальные актуальные цены, а не примеры из документации.

Создайте CSV с заголовками:

```csv
model_key,title,price,city,source
iphone 13 128 gb,iPhone 13 128 GB,25000,Новосибирск,marketplace-a
iphone 13 128 gb,iPhone 13 128 GB,27000,Новосибирск,marketplace-b
iphone 13 128 gb,iPhone 13 128 GB,26000,Новосибирск,marketplace-c
```

Цифры выше — **только пример формата**, не текущие рыночные котировки. Используйте реальные актуальные сравнимые предложения; не смешивайте разные модели, память и состояние. Импорт:

```bash
python main.py import-market market.csv
```

Для импорта объявлений можно использовать CSV/JSON с полями `title`, `price`, `url`, `model_key`, `category`, `city`, `description`, `published_at`, `image_url`, `delivery_cost`, `repair_cost`, `commission_pct`. Поля `market_price` и `market_samples` принимаются, только если `market_samples` не меньше 3.

```bash
python main.py import-listings listings.csv
python main.py deals
python main.py deals --all
```

## Основные настройки .env

- `SEARCH_CITY=Новосибирск` — метка города;
- `MIN_DISCOUNT_PERCENT=25` — минимальная скидка относительно медианы;
- `MIN_PROFIT_RUB=1500` — минимальная ожидаемая прибыль;
- `MAX_RISK_SCORE=40` — порог допуска риска;
- `MAX_LISTING_AGE_HOURS=72` — максимальный возраст объявления в часах;
- `MAX_MARKET_DATA_AGE_DAYS=30` — максимальный возраст рыночного снимка в днях;
- `DEFAULT_COMMISSION_PCT=0` — комиссионные/налоги в процентах, если применимо;
- `POLL_INTERVAL_SECONDS=300` — интервал наблюдения;
- `DEAL_DB_PATH=data/deals.sqlite3` — путь базы данных.

Ожидаемая прибыль рассчитывается как рыночная медиана минус цена покупки, доставка, ремонт и комиссия от предполагаемой продажи. Непредвиденные траты, торг и время продажи в расчёт автоматически не входят.

## Telegram-команды

- `/start` или `/help` — помощь;
- `/id` — ID чата для конфигурации;
- `/deals` — лучшие свежие сделки, прошедшие фильтры;
- `/stats` — статистика, включая устаревшие записи;
- `/sources` — сколько RSS/Atom-лент и публичных поисков Avito настроено;
- `/scan` — разовый запуск источников из Telegram.

Для постоянной работы процесс `watch`/ `telegram` нужно держать запущенным на компьютере или сервере. Токен Telegram храните только в `.env`; не добавляйте его в Git.
